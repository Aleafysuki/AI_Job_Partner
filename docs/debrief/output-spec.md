# 报告输出规范

适用于 `report.json` 以及由它渲染出的 HTML / Word 报告。渲染阶段**只做排版，不新增结论**。

## 一、顶层结构

```json
{
  "schema_version": "1.0.0",
  "generated_at": "2026-09-28T18:20:00+08:00",
  "domain": "job-position",
  "meta": {
    "title": "岗位深度分析报告",
    "subject_alias": "该岗位",
    "counterparty_alias": "对方",
    "confidence": "medium",
    "limitations": ["转写文本缺少面试官提问部分"],
    "coverage": { "transcript_chars": 8200, "speakers": ["招聘方", "求职者"] },
    "anonymized": true
  },
  "evidence": [],
  "dimensions": [],
  "charts": {},
  "synthesis": {
    "scenarios": [],
    "decision_table": [],
    "next_action": "",
    "boundary_statement": "本报告不替当事人做决定，只把做决定所需的信息整理清楚。"
  },
  "questions": []
}
```

字段只增不删；删除字段必须升 `schema_version`。

## 二、报告正文顺序（HTML 与 Word 一致）

1. **封面信息**：标题、生成日期、脱敏代号、分析置信度。
2. **先结论**（≤ 200 字）：一句话结论 + 三档决策表归属 + 唯一下一步动作。
   - 归属只能是「可以考虑 / 需要谨慎 / 明显不匹配」之一。
   - 若证据严重不足，写"当前信息不足以归类"，**不要硬塞进某一档**。
3. **一处速览**：3–5 条最需要当事人知道的事实（每条一行，带证据编号）。
4. **可视化**：要求综合评估雷达 / 压力来源分布雷达 / 个体适配度雷达；工作量时间测算表；单位时间回报测算表。
5. **12 维度明细**：固定按 D1 → D12 顺序。每个维度小节包含：
   - 结论句（1 句）
   - 依据（分点，每条标 `[原文]` 或 `[推断]`）
   - 未知项（若无则省略）
   - 该维度产生的问题（指向 D11）
6. **验证问题清单**：按五类分组，每条前置优先级标记。
7. **三档决策表**：可以考虑 / 需要谨慎 / 明显不匹配。
8. **边界声明**：固定文案（见第一节 `boundary_statement`）。
9. **附录**：证据索引表（编号、原话、发言人、类型、topic）。

## 三、写作范式

- **先结论后依据**。每段第一句必须是可独立成立的判断句，后面才是支撑。
- **一句一事实**。禁止把"是 A 也是 B"塞进一句。
- **标注来源**：正文里用 `[原文]` / `[推断]` 前缀，与 JSON 的 `basis` 一一对应。
- **量化表达**：数字给区间并附算式，例如"约 340 分钟（170 项 × 2 分钟）"。
- **概率用定性档位**：极低 / 较低 / 中等 / 较高 / 很高。**严禁**出现百分比形式的预测。
- **不做价值判断**。禁用句式：「年轻人应该吃苦」「抗压能力都是锻炼出来的」「这么好的机会别错过」「我觉得你适合 / 不适合」。
- **不做劝阻也不做鼓励**。把取舍条件摆出来，让当事人自己选。
- **术语去行业化**：行业名词首次出现时加一句解释，或改成通用描述。
- **允许否定结论**。结论是"明显不匹配"时直接写，不需要缓和措辞。

## 四、长度控制

| 部分 | 上限 |
|---|---|
| 先结论 | 200 字 |
| 每个维度小节 | 400 字（D3、D10 因含测算可到 600 字） |
| 速览 | 5 条 |
| 问题清单 | 15 条 |
| 附录证据表 | 不限，但只收录被引用过的证据 |

维度小节超长时优先删"背景铺垫"，保留判断句、依据与未知项。

## 五、脱敏规则

**必须替换**：

- 真实姓名 → 对方 / 招聘方 / 当事人 / 某位同事
- 公司名、品牌名、门店名 → A 公司 / 该门店
- 具体地址、小区、门牌、学校名 → 该区域 / 该院校
- 能组合反查到个人的信息（如"某市某校 2023 届"→"某地某院校毕业生"）

**保留不改**：数字类信息（工时时长、薪酬区间、指标数量），分析价值高于隐私风险；但若数字本身可唯一定位（如"全市唯一一家 X"）需模糊化为"当地少数几家之一"。

脱敏在**渲染阶段统一执行**，不要只在正文改、附录不改。`meta.anonymized` 为 `false` 时必须在报告顶部提示读者，默认应为 `true`。

## 六、渲染约束（App 适配）

- **自包含**：HTML 单文件，CSS 与 JS 内联，雷达图用原生 SVG 绘制，**不引用任何 CDN、外部字体或远程图片**，断网可开。
- **亮色主题**：默认浅色底 + 深色文字，保证打印与手机端可读；不要用纯黑大面积背景。
- **响应式**：视口宽度 < 720px 时表格转卡片式堆叠，雷达图等比缩小。
- **可机器读**：`<script type="application/json" id="report-data">` 内嵌完整 `report.json`，便于 App 二次读取页面内的数据。
- **无副作用**：渲染器不发起网络请求、不写日志文件、不修改入参对象。
