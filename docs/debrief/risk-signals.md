# 风险信号库（D9 专用）

用途：扫描转写文本，命中即产出 `risk_signals[]`。

**总原则：信号不等于欺骗。** 每一条都要给出"正面理解 / 反面理解 / 其他可能"三种解释，并写清验证方式。只标风险、不给验证路径的条目视为不合格。

**单条输出结构**

```json
{
  "id": "R3",
  "category": "salary_range",
  "quote": "薪资 8000 到 15000，上不封顶",
  "reads": {
    "positive": "底薪 8000 确实存在，绩效上限高",
    "negative": "8000 是极少数人的成绩，多数人拿不到",
    "other": "底薪 8000 但含全勤与绩效基数，实际底薪更低"
  },
  "verify": {
    "ask": "薪资区间的构成是什么？无绩效时实发多少？",
    "observe": "看合同写的底薪数字，而非口头区间"
  },
  "severity": "high",
  "evidence_ids": ["E21"],
  "linked_dimensions": ["D10", "D2"]
}
```

`severity` 只能取 `high / medium / low`，表示该信号对判断的影响权重，不表示对方恶意程度。

---

## 信号清单

### 1. 模糊限定词（`hedge_words`）

命中词：平均、大概、预估、正常情况下、基本上、一般来说。

**通常意味着**：给出的是一个乐观估计，不是承诺值。
**验证方向**：把"平均"追问成"上个月最差的一周是多少"。

### 2. 否认压力型（`no_pressure_claim`）

命中词：只要认真做就可以、没有业绩压力、不难的、很轻松。

**意味着**：可能存在未说明的隐性考核，或该说法本身就是话术。
**验证方向**：问"完不成会有什么后果"，问最近三个月团队有多少人没达标。

### 3. 归因个人型（`personal_ability`）

命中词：主要看个人能力、新人前期会有人带、有人做得很好。

**意味着**：缺少稳定可达成的基准，把系统性风险转成个人问题。
**验证方向**：问"做得一般的人大概什么水平""上一位做这个岗位的人做了多久"。

### 4. 基础任务型（`base_task_claim`）

命中词：完成基础任务即可、达标线很低、随便做做就行。

**意味着**：基础任务与收入或去留可能不挂钩，会有额外的隐性门槛。
**验证方向**：问"基础任务之外还有没有其他考核指标"。

### 5. 宽幅薪资型（`salary_range`）

命中词：薪资 X 到 Y、上不封顶、多劳多得、综合收入。

**意味着**：下限通常是理想情况的叙述，而不是保底。
**验证方向**：问底薪是多少、绩效基数怎么算、拿不到绩效时实发多少。

### 6. 弹性时间型（`flexible_time_claim`）

命中词：做完了可以自由安排、时间比较灵活、不强制打卡。

**意味着**：可能是"任务量固定但时间不限"，实际会填满全部时间。
**验证方向**：问"每天是否有最低在线时长""任务量是多少"。

### 7. 预先否认型（`preemptive_denial`）

命中词：我们并不是 XX、外面说我们 XX 是不对的。

**意味着**：该标签在社会认知中确实存在，需要弄清为什么会被贴上。
**验证方向**：不直接对抗，改问具体流程细节（每天具体做什么、跟谁汇报）。

### 8. 说法不一致型（`inconsistency`）

形态：不同发言人对同一事实给出的数字或描述不同。

**意味着**：信息未经统一口径，或其中一方在美化。
**验证方向**：把这个矛盾原样拿出来问，看对方如何解释。这是**优先级最高**的一类信号。

### 9. 条件承诺型（`conditional_promise`）

命中词：如果……就……、表现好可以……、满 X 个月之后……

**意味着**：承诺带条件，条件由对方解释。
**验证方向**：问条件的具体判定标准、谁来评、写不写进合同。

### 10. 回避具体型（`evasion`）

形态：被问到具体数字或流程时，用"具体情况具体分析""看个人"绕开。

**意味着**：信息缺口，通常落在薪酬、工时、考核三处。
**验证方向**：把问题换成二选一或给区间让对方确认，减少绕开空间。

### 11. 只谈成长型（`growth_over_content`）

形态：大量篇幅讲机会、成长、平台，但几乎不提每天具体做什么。

**意味着**：实际工作内容可能不具备对外讲述的价值。
**验证方向**：强制问"昨天这个岗位的人具体做了哪几件事"。

### 12. 文化包装型（`culture_wrapping`）

命中词：狼性、奋斗者、使命必达、能者多劳、家人文化。

**意味着**：高强度要求被包装成价值观，靠内驱而非制度推进。
**验证方向**：问实际下班时间、周末安排、有无强制参与的集体活动。

## 冲突一致性检查

对每条 topic 下出现多个数字的字段，逐项做一致性比对，输出：

```json
{"field": "每月休息天数", "values": [{"value": "4 天", "speaker": "HR", "evidence_id": "E8"}, {"value": "6 天", "speaker": "主管", "evidence_id": "E15"}], "conflicting": true}
```

`conflicting = true` 的字段必须同时进入 `unknowns` 与 D11 问题清单，优先级为 `high`。
