AI Agent 开发工程师（校招/1-3 年）

岗位职责
1. 负责公司 AI Agent 应用的设计与开发，包括工具调用、多轮对话、工作流编排；
2. 与产品和业务方协作，把业务需求转化为可落地的模型应用方案；
3. 负责 RAG 检索链路的优化，包括文档切分、向量检索、召回效果评估；
4. 持续跟踪模型能力与成本，输出可量化的优化结论。

任职要求
1. 本科及以上学历，计算机、软件工程相关专业；
2. 2 年以上开发经验，至少 1 年 AI 应用相关经验；
3. 熟练掌握 Python，能够独立开发后端服务与自动化工具；
4. 熟悉大语言模型的常见使用方式，理解 Prompt 设计、Function Calling、上下文管理；
5. 有 RAG 实际项目经验，了解向量数据库（FAISS / Milvus 任一）的使用与调优；
6. 熟悉至少一种工作流编排工具（Dify / Coze / n8n）；
7. 具备良好的沟通能力，能够与非技术同学清晰对齐需求；
8. 有较强的自驱力和学习能力，能适应快速变化的技术环境。

加分项
1. 有 LangChain / 多 Agent 协作项目经验者优先；
2. 有开源项目或技术博客者优先；
3. 有 Token 成本控制或模型评测经验者优先；
4. 有 Prompt 工程化与效果评测经验者优先。
